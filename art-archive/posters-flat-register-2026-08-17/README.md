# Splash posters — flat-illustration register (archived 2026-08-17)

These are the 18 splash-carousel posters in the **flat cel/airbrush illustration**
register — hard outlines, flat colour fills, graphic-poster look — as distinct
from the **photoreal-painterly** register (soft airbrush, realistic skin, bokeh)
that matches the in-world portrait art.

They were pulled from the splash carousel rotation (`_SPLASH_DECK` in
`web/js/main.js`) because mixing the two registers read as two art styles side by
side. The live copies at `web/art/posters/<id>.webp` are slated to be **rerolled
into the photoreal register** (keeping the full-body composition, changing only
the render), which overwrites them at the same path — so these are preserved here
first, at Mario's request, for possible later use (an alternate content pack, a
style reference, or restoration).

**They still ship** in the game today: the in-game *poster* feature (not the
splash carousel) still draws from all 37 `web/art/posters/*.webp`. This folder is
a frozen copy, not the live path.

Ids: aof beam boom cherry dao fah fang gift ice mook nice noi orn praew sara toey
view yada.

`art-archive/` is outside `web/`, so it never deploys to gh-pages.
